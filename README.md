# Nancy Malhotra — Developer Portfolio

A responsive, modern dark portfolio built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — page content and sections
- `style.css` — dark theme, responsive layout, animations
- `script.js` — mobile navigation, scroll reveals, rotating role text
- `assets/avatar-placeholder.svg` — replaceable profile image placeholder
- `assets/Nancy-Malhotra-Resume.pdf` — resume download (included if the uploaded PDF was available)

## Run locally
1. Extract the ZIP file.
2. Open the `nancy-portfolio` folder.
3. Double-click `index.html`, or open the folder in Visual Studio Code and use the Live Server extension.
4. No build tools, package installation or server configuration are required.

## Add your real profile photo
1. Copy a square JPG, PNG or WebP photo into the `assets` folder, for example `profile.jpg`.
2. Open `index.html`.
3. Find the image element with `id="profile-photo"`.
4. Change its source to `assets/profile.jpg`.
5. Save and refresh the browser.

A square portrait works best. The placeholder is an original graphic, not a photograph.

## Add your social links
The resume supplied for this site contains placeholder text for LinkedIn and GitHub URLs, not actual profile links. Add your real links when ready. You can add them to the contact area in `index.html`.

## Publish online
You can host this static site on GitHub Pages, Netlify or any standard static web host. Upload the contents of this folder (including `assets`) and set `index.html` as the entry page.

## Personal details
Content is based on the supplied resume. Verify contact details and update any information that changes before publishing publicly.


## Featured projects
- **Quiz Application — Group Project:** Python, Tkinter and MySQL. The portfolio includes a representative Tkinter interaction snippet and a working-flow explanation. The original group source files were not supplied, so the snippet is illustrative rather than a copy of the original project.
- **Spendwise — Expense Tracker — Personal Project:** HTML, CSS and vanilla JavaScript. Open `assets/projects/spendwise/index.html` from the portfolio or use the “Try working app” link in the Projects section. The full working app source is included.

The Spendwise app supports adding, editing and deleting expenses, validation, monthly and all-time totals, category/date filters, sorting, and browser LocalStorage persistence. Its records remain in the current browser and are not synced to an account.
